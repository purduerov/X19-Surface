# ROV Surface Interface — Frontend

This directory contains the frontend web interface for our ROV. It displays real-time telemetry data (depth, internal pressure, temperature, orientation, electrical load), video stream feeds from the ROV cameras, control mapping displays, and log viewers.

It is built using **HTML5**, **Tailwind CSS**, **JavaScript (ES6+)**, and **Bootstrap Icons**, served via a **Python Flask** backend.

---

## 🎨 Tailwind CSS Architecture & How It Works

We use Tailwind CSS to maintain a standardized, dark-mode HUD theme across all template pages without needing internet/Wi-Fi in field operations.

```
                  ┌──────────────────────────────┐
                  │   src/tailwind.config.js     │
                  │  (Custom ROV Colors & Fonts) │
                  └──────────────┬───────────────┘
                                 │
                                 ▼
┌──────────────────────┐  Tailwind CLI   ┌──────────────────────────────┐
│  static/components.css│ ──────────────> │     static/tailwind.css      │
│  (@layer components) │ (Build Process) │ (Offline Compiled Stylesheet)│
└──────────────────────┘                 └──────────────┬───────────────┘
                                                        │ Loaded locally
                                                        ▼
┌──────────────────────────────┐              ┌──────────────────────────────┐
│     templates/base.html      │ ────────────>│  templates/innovative_ui.html│
│   (Master Jinja Blueprint)   │  Extends     │  (Page Views using Tailwind) │
└──────────────────────────────┘              └──────────────────────────────┘
```

### File Responsibilities & Interactions

1. **[templates/base.html](src/templates/base.html) — Master Blueprint**
   - The root Jinja2 layout extended by all frontend views (`innovative_ui.html`, `all_cameras.html`, etc.).
   - Loads the compiled local stylesheet `<link rel="stylesheet" href="/static/tailwind.css">` so pages work **100% offline without Wi-Fi**.

2. **[src/tailwind.config.js](src/tailwind.config.js) — Design System Tokens**
   - Declares custom ROV theme variables (hex colors, fonts, z-indices):
     - `bg-rov-dark` (`#02142b`)
     - `bg-rov-panel` (`#001c38`)
     - `bg-rov-item` (`#01284f`)
     - `border-rov-border` (`#033a66`)
     - `text-rov-accent` (`#00e6ff`)
     - `font-orbitron`

3. **[static/components.css](src/static/components.css) — Custom Component Abstractions**
   - Holds reusable component classes using Tailwind's `@apply` directive (`.data-card`, `.modal-overlay`, `.modal-card`, `.dashboard-grid`, `.speedo-grid`, `.command-box`).
   - Keeps individual HTML template files clean, human-readable, and free of massive inline utility strings.

4. **[static/tailwind.css](src/static/tailwind.css) — Offline Compiled CSS Bundle**
   - The single, minified, production-ready CSS file generated by the Tailwind CLI. It contains all used utility classes and component abstractions packaged locally for field operations.

## 🛠️ Tailwind CLI Installation Guide (Linux, macOS, Windows)

To recompile CSS when making design or component changes, you will need **Node.js** (v18+) or the standalone **Tailwind CLI binary**.

### Option A: Installation via Node.js / NPM (Recommended)

#### Linux (Ubuntu / Debian / ROS OS)
```bash
# 1. Install Node.js & npm (using NVM)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20

# 2. Verify installation
node -v
npm -v
```

#### macOS
```bash
# Using Homebrew
brew install node

# Or using NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 20
```

#### Windows
```powershell
# Using winget in PowerShell
winget install OpenJS.NodeJS

# Or download Node.js LTS installer from https://nodejs.org/
```

Once Node.js is installed on any OS, navigate to the `src/frontend` directory and install dependencies:
```bash
cd src/frontend
npm install
```

---

### Option B: Standalone Tailwind CLI Binary (No Node.js Required)

If your field system cannot install Node.js, download the official standalone executable:

- **Linux (x64)**:
  ```bash
  curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64
  chmod +x tailwindcss-linux-x64
  sudo mv tailwindcss-linux-x64 /usr/local/bin/tailwindcss
  ```
- **macOS (ARM / Apple Silicon)**:
  ```bash
  curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64
  chmod +x tailwindcss-macos-arm64
  sudo mv tailwindcss-macos-arm64 /usr/local/bin/tailwindcss
  ```
- **Windows (x64)**:
  - Download `tailwindcss-windows-x64.exe` from [Tailwind Releases](https://github.com/tailwindlabs/tailwindcss/releases) and rename it to `tailwindcss.exe`.

## ⚡ Running the Frontend (Single-Command Dev Environment)

We provide a convenient `./dev-run` script that launches both the **Tailwind CSS Watcher** and the **Flask Backend Server** in a single terminal session:

```bash
cd src/frontend
./dev-run
```

*When you press `Ctrl+C` in your terminal, the script automatically shuts down both Flask and the background Tailwind watcher cleanly.*

### Individual Commands
If you prefer running commands manually in separate terminals:

```bash
# 1. Start Tailwind CSS Watcher
npm run dev:css

# 2. Start Flask App
python3 src/app.py

# 3. Build Minified Production CSS Bundle (Before deploying / committing)
npm run build:css
```

## ❓ FAQ

### Why use a local compiled `tailwind.css` file instead of a CDN?
ROVs are deployed in pools, lakes, and ocean sites where there is **no internet access or Wi-Fi**. Loading a CDN script tag breaks the UI when offline. Compiling `tailwind.css` locally guarantees the interface works 100% offline.

### How do messages get from ROS2 to the frontend?
The surface computer runs a ROS2 node (`ui_subscriber.py`). It converts ROS2 topic messages to JSON and emits them via Flask-SocketIO to the webpage JS listeners in real time.
